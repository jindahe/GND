the historical `L=8` point and the pilot cv was slightly above the `0.06` gate:

```bash

  L_VALUES=8 \
  TRAIN_SEEDS='4 5 6 7 8' \
  scripts/run_p16_l16_ntrain400k.sh
```

The first sandboxed launch could generate the dataset but failed at GPU
training because `torch.cuda.is_available()` was false inside the sandbox. The
same run id and configuration were continued outside the sandbox; generated
datasets were reused and the training/evaluation stages completed on `cuda:0`.

Interpretation:

- The 8-seed `p18` mean is substantially above the previous historical
  recommended `L=8` point.
- The final cv is `0.050360`, which is below the `0.06` usable-baseline gate
  but slightly above the stricter `0.04..0.05` formal-result range.
- The train-seed spread is the main uncertainty: `0.132981` compared with mean
  bootstrap std `0.050881`.
- Because the result materially changes the `L=8 -> L=10` bridge, this run
  supersedes the historical single-point `L=8` recommendation in
  `docs/MI_FIT_POINTS.csv`.
