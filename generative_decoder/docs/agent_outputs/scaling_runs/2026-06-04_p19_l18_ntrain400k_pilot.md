## Diagnostics

Seed 5 is the main concern:

- Its `BA` run selected best epoch 19, much earlier than the other `BA` runs.
- Later seed-5 `BA` epochs showed NLL values in the `6e3` range before early
  stopping.
- Its `BA` test NLL, `190.030531`, is well above the other `BA` test values.
- Its MI, `10.379700`, is the maximum of the seed set.

Seed 7 is also high, with MI `10.334045`, but it does not show the same obvious
training failure signature in the saved best/test metrics.

  borderline usable because cv is `0.060001`.
- The aggregate is recorded as the provisional `L=18` recommended fit point
  because it is the only completed largest-size result, but it should not be
  treated as a clean formal point.
- Any conclusion that depends strongly on `L=18` should report sensitivity to
  seed 5, and probably seed 7.
